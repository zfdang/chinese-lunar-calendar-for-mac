# 节日来源与收录范围

本文列出万年历收录的节日、日期规则、数据来源及适用范围。
在“设置 → 显示节日”中，可以分别开关节日分类，并在“国外公共假日”中选择国家或地区。
显示设置同时影响月历、日期详情和“即将到来”列表。

国外公共假日默认关闭，可以同时启用多个日历。它们只增加节日信息，不会将中国的工作日标记为放假，也不改变中国的调休安排。

## 分类

| --- | --- | --- |

| 常见西方节日（美式日期） | 情人节、愚人节、母亲节、父亲节、万圣节、感恩节、平安夜、圣诞节，共 8 项 | python-holidays 的美国日历，以及美国国会图书馆的愚人节资料，见对应日期表 |

| 国际纪念日 | 消费者权益日、世界红十字日、世界环境日、国际禁毒日、国际和平日、联合国日、世界艾滋病日、世界人权日，共 8 项 | 联合国及相关组织资料，逐项来源见“国际纪念日”表 |
| 国外公共假日 | 英国各地区、美国联邦、法国全国、德国全国的公共假日 | python-holidays，地区范围见“国外公共假日与第三方来源”表 |

多个日历在同一天有同名节日时合并显示，详情和“即将到来”注明国家；同名的个人事件仍保留。
国外公共假日排在本地节日和个人事件之后，避免挤掉月历格子中的传统节日名称。
补假与节日本日分别显示，例如“美国独立日”和“美国独立日（补假）”。

## 传统节日

本分类的日期规则由本项目维护，对应的公历日期随农历年份变化。规则定义见 [Festivals.swift](../Sources/LunarCore/Festivals.swift)。

| 名称 | 农历日期或规则 |
| --- | --- |
| 春节 | 正月初一 |
| 元宵节 | 正月十五 |
| 端午节 | 五月初五 |
| 七夕 | 七月初七 |
| 中秋节 | 八月十五 |
| 重阳节 | 九月初九 |
| 腊八节 | 腊月初八 |
| 除夕 | 农历年的最后一天，即腊月的最后一天，可能为廿九或三十 |

固定农历日期的节日不在闰月重复显示。除夕按农历年的最后一天计算，不固定为腊月三十。
清明作为二十四节气之一独立计算和显示，不属于本表的 8 项农历节日。

## 国外公共假日与第三方来源

国家日历及表中标注为 python-holidays 的西方节日使用 [python-holidays 0.107](https://github.com/vacanza/holidays/tree/v0.107)，采用 MIT 许可证。
上游的[使用说明](https://holidays.readthedocs.io/)介绍了国家、地区和节日分类。

| 国家 | 可选择的范围 | 不包含的范围 |
| --- | --- | --- |
| 英国 | 英格兰、威尔士、苏格兰、北爱尔兰，各地区可分别选择 | 未选中地区的额外公共假日 |
| 美国 | 联邦公共假日 | 各州的额外假日 |
| 法国 | 全国公共假日 | 地区及海外领地的额外假日 |
| 德国 | 全国公共假日 | 各州的额外假日 |

这些国家日历不包含各国完整的民俗节日清单。
数据生成时使用公共假日类别 `PUBLIC`；英国指定所选地区，美国、法国、德国采用全国范围。
情人节、母亲节、父亲节、万圣节、感恩节、平安夜、圣诞节这 7 项常见西方节日，从美国的 `PUBLIC` 与 `UNOFFICIAL` 类别中选取。
第三方名称固定使用 `en_US`，中文译名由本项目维护；数据包含上游提供的历史起始年份、一次性公共假日和补假。

数据覆盖应用支持的 1901–2099 年范围，但不是各国完整的历史日历：上游未提供的历史时期不会自行补造，例如德国全国日历从 1991 年起提供。
未来年份按固定版本中的规则推算，政府之后公布的变化需要重新生成数据并随应用更新。
国家日历随应用打包，日常使用不访问第三方服务，也不需要安装 Python。
“更新假日信息”入口只更新中国国务院放假调休安排，不下载国家日历。

## 升级与导入说明

对于使用旧分类设置的用户，“西方节日”开关的显示选择会用于“常见西方节日（美式日期）”。
“纪念日”曾是一个同时包含国内、国际条目的分类：如果升级前已隐藏该分类，升级后“国内纪念日”和“国际纪念日”都会隐藏，之后可分别调整。

导入旧版 `festivals.js` / `events.js` 时，程序会识别其中的内置默认项，只将用户添加的条目作为个人事件导入。
识别范围包括当前未收录的历史默认项，例如“抗日战争胜利（8 月 15 日）”“北京奥运会开幕日（2008 年 8 月 8 日）”“抗战胜利日假期（2015 年 9 月 3 日）”，避免把它们误导入为个人事件。
已经保存在自定义日期文件中的个人事件不会因内置节日清单而被删除或修改。

## 数据维护（开发者）

使用 python-holidays 的日期数据由生成脚本预先计算，并编译到应用中。以下命令用于维护数据，不是使用应用的必要步骤：

```sh
python3 -m venv /tmp/festival-tools
/tmp/festival-tools/bin/pip install -r scripts/festival-requirements.txt
/tmp/festival-tools/bin/python scripts/generate-festivals.py
/tmp/festival-tools/bin/python scripts/generate-festivals.py --check
```

在 `WanNianLiSwift` 目录下运行。升级依赖时应同时更新生成器版本、来源链接、此说明和快照，审阅日期与译名变化后再提交。
新出现且未翻译的名称会使生成失败，避免把不完整的翻译静默发布。
完整上游版权声明保存在 [holidays-LICENSE.txt](holidays-LICENSE.txt)，构建时一并放入应用的 `Contents/Resources/ThirdPartyNotices/`。
