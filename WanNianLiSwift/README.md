# WanNianLiSwift — Mac 菜单栏万年历

点一下菜单栏，查看农历、节气、放假调休，以及即将到来的生日和纪念日。支持 Apple 芯片与 Intel 芯片，适用于 macOS 13 或更新版本，免费开源。

[下载与产品介绍](../README.md) · [官方网站](https://calendar.zfdang.com) · [更新历史](../CHANGELOG.md)

## 日常使用

- 点击菜单栏的日期图标展开月历；点击某一天，查看农历、干支、生肖和当天事件。
- 在右上角添加家人的农历生日、公历生日或纪念日，支持每年重复或仅一次，也可以导入、导出备份。
- 月历下方显示最近事件和倒计时；点击列表图标，查看未来 90 天内最多 6 项，点击事件可跳转到当天。
- 在设置中选择节日分类及英国、美国、法国、德国的公共假日日历，调整外观或开启自动启动。
- 同一天的事件在详情右侧显示，最多使用两行；醒目事件用红色，普通事件用正常文字色，节气用蓝色。悬停可查看完整内容。
